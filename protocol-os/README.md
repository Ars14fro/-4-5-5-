# Protocol OS ⚡ — персональный ассистент дисциплины

PWA «личная операционная система дня», собранная по спецификации и Мега-гайду v2.6.
Zero overhead · Mobile & Dark first (OLED-black) · Local-first (все данные в браузере) · AI-Native JSON.

---

## 🚀 Как запустить

### Вариант 1 — просто открыть (30 секунд)
Открой файл **`index.html`** в браузере смартфона или компьютера (двойной клик / отправить себе в мессенджер и открыть).
Всё приложение — один самодостаточный файл: стили, скрипты, иконки и PWA-манифест вшиты внутрь. Интернет не нужен.

### Вариант 2 — как настоящее приложение на смартфоне (PWA)
1. Залей папку `protocol-os/` на любой статический хостинг (GitHub Pages, Netlify, Vercel) или подними локально:
   ```bash
   cd protocol-os && python3 -m http.server 8080
   ```
2. Открой адрес в Chrome/Safari смартфона.
3. **iOS Safari:** «Поделиться» → «На экран „Домой”». **Android Chrome:** меню → «Установить приложение» / иконка «+» в адресной строке.
4. Приложение откроется без рамок браузера, с иконкой и работает офлайн (service worker `sw.js` кеширует всё).

## 🔔 Уведомления и таймеры
- При первом запуске приложение попросит разрешение на push — дальше в момент начала каждого блока приходит уведомление «16:30 — Спринты ⚡» с главным правилом.
- Сигналы помодоро и углеводного окна: звук (Web Audio) + вибрация + полноэкранный алерт; таймеры переживают перезагрузку страницы.
- Приложение не спорит с системным режимом «Не беспокоить» — тишина регулируется ОС.

##  Данные и приватность
Всё хранится локально в `localStorage` (ключи `pos.*`): расписание, отметки по датам, вода, чек-минимум, таймеры. Никаких серверов, регистраций и аналитики. Экспорт JSON = твой бэкап.

## 🛠 Структура проекта
```
protocol-os/
├── index.html          ← ГОТОВОЕ приложение (самодостаточное, открывать этот файл)
├── manifest.json       ← PWA-манифест для хостинга
├── sw.js               ← service worker (офлайн)
├── assets/             ← иконки (192/512/maskable/apple-touch)
├── screenshots/        ← скриншоты всех экранов
├── PLAN.md             ← план разработки и архитектура
└── src/                ← исходники для правок
    ├── template.html   (каркас + PWA-метатеги)
    ├── styles.css      (дизайн-система)
    ├── data.js         (весь план недели из Мега-гайда v2.6, 112 блоков)
    └── app.js          (логика: таймлайн, шторка, таймеры, валидатор)
```
Пересобрать `index.html` после правок исходников: `python3 build.py` (нужен только Pillow для иконок).

## 🆕 v1.1 — что добавлено после первой сборки

2. **«День сдвинулся?» (+30 / +60 мин)** — панель на таймлайне: сдвигает все будущие блоки сегодняшнего дня, не трогая шаблон недели; бейдж «сдвиг +30′» на карточках, сброс в один тап.
3. **🅱️ План Б (сжатый день)** — кнопка в шапке: таймлайн сворачивается до чек-минимума + 4 опорных блока (утро, тренировка, вечерний уход, сон). Для дней, когда всё пошло не так.
4. **Отсчёт до отбоя + тёплый dim-режим** — «🌙 до отбоя 3 ч 40 мин (21:30)» в шапке; после 20:00 интерфейс сам переходит в янтарную палитру без синего спектра (кнопка 🌙: авто/вкл/выкл).
5. **🧠 Конструктор промпта для ИИ** — в JSON-вкладке: собирает готовый промпт = факты недели (% выполнения, проваленные блоки, вода, чек-мин) + цель + твой комментарий + весь текущий JSON. Копировать → вставить в ChatGPT/Claude.
10. **🫁 Дыхание 6/12** — утилита внутри блока «Вечерний уход»: анимированный круг, 15 циклов «вдох 6 — выдох 12», сигнал по окончании.
11. **Мягкие напоминания 24/7** — тумблер в «Привычках»: ротация пингов (осанка/мьюинг/20-20-20/телефон) раз в 2 ч + пинг по воде, только в окнах 6:30–7:00 и 15:00–21:00, без звука.
