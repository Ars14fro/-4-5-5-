# Protocol OS — План разработки

**Версия:** 1.0 · **Дата:** 05.10.2026
**Продукт:** персональный ассистент дисциплины — PWA для смартфона, mobile & dark first, local-first.

---

## 1. Цели и принципы

| Принцип | Реализация |
|---|---|
| Zero Overhead | Без регистрации, стриков, уровней. Только факты: время, блок, статус |
| Mobile & Dark First | OLED-black тема, управление одной рукой, bottom navigation, bottom sheet |
| Local-First | Все данные в `localStorage` браузера. Работа без интернета |
| AI-Native JSON | Экспорт недели в JSON одной кнопкой → правка в ChatGPT/Claude → вставка обратно с валидатором |

## 2. Технологический стек

- **Один самодостаточный файл `index.html`** (инлайн CSS + JS, data-URI манифест и иконки) — открывается откуда угодно, не требует сервера.
- Дополнительно: `manifest.json`, `sw.js`, `assets/icon-*.png` — для полноценной установки как PWA при размещении на любом хостинге (GitHub Pages, Netlify…).
- Без фреймворков и зависимостей: чистый Vanilla JS (ES2020+), CSS-переменные, Web Audio API (сигналы таймеров), Notification API (пуши), Vibration API.
- Хранение: `localStorage`, ключи `pos.*`. Состояние разделено: **данные плана** (неделя) и **состояние дня** (выполнение, вода, чек-минимум — с привязкой к дате, автосброс в полночь).

## 3. Архитектура данных (JSON-схема)

```jsonc
{
  "meta": { "name": "Protocol OS", "version": 1 },
  "week": {
    "monday": {                          // monday..sunday
      "label": "Понедельник",
      "accent": "Качалка: ноги + спина 💪",
      "schedule": [
        {
          "start": "06:00",              // обязательно, HH:MM
          "end": "06:30",                // обязательно, HH:MM

          "tag": "routine",              // routine|sport|study|food|care|sleep

```

## 4. Экраны и модули

### Модуль A — Таймлайн (вкладка 1)
1. Header: дата + день недели + акцент дня, стрелки ‹ ›, кнопка «Сегодня».
2. Вертикальная лента с масштабом минут; блоки — абсолютное позиционирование.
3. Линия «Now» — обновляется каждые 20 сек, видна только на сегодняшнем дне.
4. Состояния карточек: **текущая** (акцентная рамка, свечение, крупнее, обратный отсчёт «Осталось N мин», быстрая кнопка ✓), **будущая** (приглушённая), **прошедшая выполненная** (затемнённая + зелёная галочка), **прошедшая пропущенная** (маркер «Не выполнено»).
5. Автопереключение статусов по реальному времени; любой прошедший блок можно вручную перевести в «Выполнено» и обратно (тап по чекбоксу).
6. Пуш-уведомление в момент начала блока (заголовок: «16:30 — Спринты ⚡», тело: callout или первая строка details).

### Модуль B — Шторка блока (Bottom Sheet)
1. Свайп-вниз / крестик для закрытия, drag-handle, высота ~88%.
2. Шапка: время, заголовок, тег-чип категории (цвет по тегу).
3. Callout-плашка (⚠️/⛔) при наличии.
4. Details: структурированный текст, строки с «•/—/⛔» рендерятся списком, `⛔`-строки подсвечиваются.
5. Контекстные утилиты:
   - `pomodoro` → встроенный таймер 25/5 с циклами, визуальный круг прогресса, защита от случайного закрытия (подтверждение), звуковой сигнал;
   - `carb_timer` → «Запустить таймер углеводов (35 мин)», по окончании звук + нотификация «Окно открыто: можно углеводы».
   - Таймеры переживают перезагрузку (окончание хранится в localStorage).
6. Закреплённая внизу кнопка «Отметить выполненным» / «Снять отметку».

### Модуль C — Привычки 24/7 (вкладка 2)
1. Гидратация: цель 2.5–3 л, шкала заполнения с анимацией, кнопка «+250 мл», автосброс в полночь (по дате).
2. «Постоянный фокус»: мьюинг, posture check, 20-20-20, социальный тестостерон.
3. «Чек-минимум»: 10 интерактивных пунктов спасения дня (по дате).
4. Памятки бумажного блокнота: To-Do 1+3+5, метод Пифагора, 5 благодарностей — без полей ввода.

### Модуль D — Управление (вкладка 3), сегменты «Конструктор» / «JSON»
1. **Конструктор:** селектор ПН–ВС; список блоков (drag-and-drop + стрелки ↑↓); редактирование (start/end — селекторы времени, title, tag, callout, tools, details); «+ Добавить блок»; удаление с подтверждением. Изменения сразу в localStorage.
2. **JSON:** «Скопировать текущий JSON» (clipboard + fallback-текстареа + скачивание файла); поле вставки; «Применить изменения».
3. **Валидатор (защита от ошибок ИИ):**
   - синтаксис: перехват `JSON.parse`, перевод «position N» → номер строки;
   - схема: наличие week/7 дней/schedule, обязательные start/end/title, формат HH:MM, end > start, tag из белого списка, tools из белого списка, пересечения блоков — предупреждение;
   - при любой ошибке старые данные НЕ трогаются, поле подсвечивается красным, выводится человекочитаемый список («День „Среда", блок 4 „Качалка": не указано время окончания»);
   - при успехе — зелёный тост «План успешно обновлён».
   - «Сбросить к заводскому плану» с подтверждением.

## 5. Уведомления и звук
- Запрос разрешения Notification API при первом запуске (по тапу, чтобы не блокировался).
- Тикер каждые 20 с: начало блока сегодня → Notification (+ вибрация, + beep, если вкладка активна). Дедупликация по «дата+start».
- Сигналы таймеров: Web Audio API (короткий beep-сериал) + вибрация; при активной вкладке — полноэкранный алерт-оверлей.
- Подчинение системному «Не беспокоить» — на стороне ОС, приложение ничего не форсирует.

## 6. Дизайн-система
- Палитра: `#000/#0a0a0c` фон, `#131316` карточки, `#1e1e23` бордеры, текст `#e8e8ea`/`#8a8a92`, акцент `#3ddc97` (cyan-green), warn `#ffb454`, danger `#ff5c5c`.
- Цвета тегов: routine — серый, sport — зелёный, study — синий, food — оранжевый, care — фиолетовый, sleep — индиго.
- Типографика: системный стек (SF Pro / Roboto), крупные заголовки, tabular-nums для времени.
- Safe-area insets, нижняя навигация 3 вкладки (Таймлайн / Привычки / Управление), тач-цели ≥44px.

## 7. Этапы сборки
1. Каркас: HTML-скелет, CSS-тема, нижняя навигация, переключение вкладок.
2. Данные: полный DEFAULT_DATA (7 дней из Мега-гайда v2.6) + слой хранилища.
3. Таймлайн: рендер ленты, now-линия, статусы, отметки, навигация по дням.
4. Bottom sheet: детали, callouts, кнопка выполнения, свайп-закрытие.
5. Таймеры: помодоро, углеводное окно, звук, персистентность.
6. Привычки 24/7: вода, фокус, чек-минимум, блокнот.
7. Конструктор расписания.
8. JSON-импорт/экспорт + валидатор.
9. Уведомления, PWA (манифест, иконки, service worker, offline).
10. Тестирование сценариев дня (use-case из спецификации), финальная упаковка.

## 8. Риски и решения
| Риск | Решение |
|---|---|
| iOS Safari ограничивает Notification API в PWA | Звук + вибрация + алерт-оверлей как fallback |
| Clipboard API недоступен без https | Fallback: textarea + выделение + скачивание .json |
| Ошибка ИИ в JSON ломает план | Данные не перезаписываются до полного прохождения валидатора |
| Потеря данных браузера | Экспорт JSON = бэкап; кнопка скачивания |
